Paytm pill button. Primary (blue) for the main action, secondary (outline) and ghost for lower emphasis, plus navy / danger / success / neutral.

```jsx
<Button variant="primary" size="lg" icon="indian-rupee">Pay ₹2,500</Button>
<Button variant="secondary" size="md">Activate</Button>
<Button variant="danger" size="md" icon="shield-alert">Block</Button>
```

- Sizes: `lg` (48) primary CTAs, `md` (40) inline, `sm` (32) dense rows. `block` stretches full width. Always pill-shaped.
